# 链霉菌 NAP 结合位点的序列预测

用机器学习从 DNA 序列预测链霉菌类核相关蛋白（Lsr2）在哪里结合，
并量化模型的判断依据来自"碱基组成"还是"序列结构"。

## 动机

链霉菌产生约三分之二的抗生素。它用 NAP 压制大量沉默的基因簇，
而解开这些压制就可能发现新抗生素。但确认 NAP 结合位点只能靠昂贵的
ChIP-seq 实验。**本项目检验：能否只从序列预测结合位点，
以及模型学到的是组成还是序列。**
